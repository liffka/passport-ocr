# Результаты проверки

Групповая CV фиксированной политики: 5 частей, 3 повтора.

Словари для каждого фолда обучены без записей проверяемой части. Повторные снимки одного паспорта остаются вместе. Пороги заданы заранее в policy.json.

- Повтор 1, seed 20261025: 595 принято из 3000, 5 несовпадений.
- Повтор 2, seed 20270998: 594 принято из 3000, 5 несовпадений.
- Повтор 3, seed 20280971: 594 принято из 3000, 5 несовпадений.

Во всех повторах несовпадения приходятся на одни и те же пять документов:

- tr_01506
- tr_01665
- tr_01765
- tr_02287
- tr_02818

Скорее всего, причина этих пяти расхождений - опечатки в разметке. Без исходных фотографий это гипотеза. Все пять учитываются как ошибки стандартного оценщика.

Правила ранее разрабатывались на этом наборе, поэтому проверка не полностью слепая. Повторы перекрываются и не являются независимыми выборками.

В каждом каталоге grouped_cv/repeat-N после запуска создаются answers.jsonl и labels.jsonl для сверки стандартным evaluate.py. Сохранённые метрики приведены рядом; предсказания и копии разметки фолдов воспроизводятся из исходных данных.

```sh
python run_cv.py --folds 5 --repeats 3
python evaluate.py validation/cv_final/grouped_cv/repeat-0/answers.jsonl validation/cv_final/grouped_cv/repeat-0/labels.jsonl
```
