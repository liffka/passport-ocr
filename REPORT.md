# Постобработка OCR паспорта РФ

Решение и валидация · CPU, стандартная библиотека Python, без внешних зависимостей · 25.10.2026

Test: 2000 документов · 517 принято (25.9%) · 1483 отклонено

## 1. Задача и архитектура решения

Цель - максимизировать число принятых документов при отсутствии ошибочных принятий. Документ считается корректным, если все десять полей совпадают с разметкой и паспорт действителен на 01.10.2026. Алгоритм объединяет геометрические проверки, сверку зон распознавания, справочник подразделений и проверку дат.

1) **Геометрический контроль строк:** строки визуальной зоны собираются по координатам с проверкой верхней и нижней границы поля, а также межстрочных разрывов. Пропуск любой строки ведёт к отказу.

2) **Сверка визуальной зоны и MRZ:** ФИО сопоставляются по правилам кодирования кириллицы внутренних паспортов. При оценке уверенности MRZ символы '<' не учитываются. В нижней строке проверяются допустимый алфавит, структура и четыре контрольные цифры. Восстанавливается четвёртая цифра серии. Ограниченные исправления разрешены при достаточном подтверждении; уверенные противоречия ведут к отказу.

3) **Свободные тексты:** орган выдачи сопоставляется со справочником DaData и названиями из обучения. Неоднозначные подстановки, изменение пунктуации и грамматических окончаний запрещены. Место рождения не достраивается: проверяются полнота рамки и уверенность символов. Запрета незнакомых имён нет.

4) **Проверка дат:** календарная корректность, выдача не ранее 14-летия и не позже даты оценки, сроки замены в 20/45 лет и 90 календарных дней после возрастной границы. Доступа к реестрам утраченных или аннулированных паспортов нет; полную юридическую действительность по OCR установить нельзя.

## 2. Анализ ошибок и расхождений с разметкой

Для ФИО используется согласованность визуальной зоны и MRZ: наличие имени в обучающем словаре не требуется. Это позволяет принимать редкие имена при достаточном подтверждении распознавания.

На train принято 630 документов; пять не совпали с разметкой: tr_01506 - КАБЛЯХБАР / КАБЛЯЖБАР; tr_01665 - ДЖАМБИЧИ / ДЖАМБИУИ; tr_01765 - ХАСАНЗЯН / ХАОАНЗЯН; tr_02287 - МУТЯНСКИЙ / МУТЯНСЖИЙ; tr_02818 - ЕВГЕНИЙ / ЕВТЕНИЙ. **Скорее всего, эти пять расхождений связаны с опечатками в разметке.** В четырёх случаях с ФИО визуальная зона и MRZ совпадают; место рождения в MRZ отсутствует. Без фотографий гипотезу подтвердить нельзя, поэтому все пять учитываются как ошибки официального оценщика.

## 3. Протокол оценки

Групповая кросс-валидация: 5 фолдов, 3 повтора с фиксированными seed. Все снимки одного паспорта относятся к одному фолду; источники сбалансированы между фолдами. Словари органов выдачи обучаются только на обучающей части. Каждый документ получает одно проверочное предсказание в каждом повторе. Пороги зафиксированы в policy.json.

Это CV фиксированной политики, без вложенного подбора порогов. Правила и пороги ранее разрабатывались на этом наборе, поэтому проверку нельзя считать полностью слепой. Повторы используют те же документы и не увеличивают число независимых наблюдений втрое.

## 5. Прогноз для test

Принято 517 из 2000 документов (25.9%).
Прогноз ошибок среди принятых: около 6.

Распределение принятых по источникам: mobile: 164 test / 188 CV; mobile_v2: 207 test / 149 CV; web: 146 test / 258 CV. Прогноз рассчитан по модели Beta-биномиального сглаживания Джеффриса Beta(0,5; 0,5) отдельно для каждого источника снимков на основе первичного повтора CV. Расчётное матожидание несовпадений составляет **6,16**, округлённо **6** (условный 95%-й предиктивный интервал: [0; 13]).

Прогноз предполагает переносимость характеристик источников и независимость документов. Разметка test недоступна; фактическое число ошибок неизвестно. Целевой нулевой уровень ошибок на локальной проверке не достигнут.

## 6. Воспроизводимость и запуск

Решение полностью детерминировано, протестировано 39 юнит-тестами и работает офлайн на стандартном CPU без внешних библиотек.

```sh
python postprocess.py data/test_predictions.jsonl answers.jsonl
python run_cv.py --folds 5 --repeats 3
python -m unittest discover -s . -p "test_*.py"
```

Нормативная база: Постановление Правительства РФ № 2267 (п. 24, замена паспорта в 20/45 лет); Приказ МВД РФ № 773 (приложение 24, формат MRZ). Справочник кодов: DaData (CC BY-SA 4.0).
